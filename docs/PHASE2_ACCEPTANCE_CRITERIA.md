# Phase 2 Acceptance Criteria

- Compiled Windows application replaces PowerShell UI.
- Business rules covered by automated tests.
- SQLite replaces JSON as primary storage.
- Existing `guests.json` can be imported.
- Installer is versioned and supports upgrade/repair/uninstall.
- Notifications use Windows toast identity instead of tray balloons.
- App logs errors to a known support location.
- App supports backup and restore.
- App is tested at common Windows scaling levels.
- Release package contains no test guest data.
