# 55 Day Counter

Windows desktop app for tracking hotel guest 55-day cycles.

Check-in is counted as day 1, so the 55th day is `check-in date + 54 days`.

## Current Status

- `src/` contains the Phase 2 .NET WinForms app and shared business rules.
- `legacy/powershell-pilot/` contains the working Phase 1 PowerShell pilot app.
- `installer/phase1-bootstrap/` contains the current installer/uninstaller support files.
- `dist/` is generated by release builds and is intentionally ignored by Git.

## Run The .NET App

```cmd
scripts\Run-DotNetApp.cmd
```

## Build And Test

```cmd
scripts\Test-DotNetApp.cmd
```

Equivalent commands:

```powershell
dotnet build FiftyFiveDayCounter.slnx -c Release
dotnet run --project tests\FiftyFiveDayCounter.Core.Tests\FiftyFiveDayCounter.Core.Tests.csproj -c Release --no-build
```

## Installer And Uninstaller

Current one-step installer:

```text
installer\phase1-bootstrap\55DayCounterInstaller.exe
```

Current uninstaller helpers:

```text
installer\phase1-bootstrap\Uninstall-55DayCounter.cmd
installer\phase1-bootstrap\Uninstall-55DayCounter.ps1
```

To rebuild the installer package:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\Build-Release.ps1
```

Generated release files are written to `dist/`.
The script also refreshes `installer\phase1-bootstrap\55DayCounterInstaller.exe` so the repo has the current one-step installer.

## Data Policy

Runtime guest data is stored as `guests.json` next to the installed app. Local working data is kept under `local-data/` and ignored by Git. Only sanitized examples such as `samples/guests.sample.json` should be committed.

## Features

- Add, edit, complete, and cancel guest cycles.
- Automatically calculate the 55th day and notification date.
- Search and filter records by status.
- Color-code active, due soon, due today, overdue, completed, and canceled guests.
- Preview `Today's List` for overdue guests plus guests checking out today or in the next 5 days.
- Export all records or today's list for Excel use.
- Show notifications while the app is open, with scheduled daily checks in the Phase 1 installer.

See `docs/INSTALLATION.md` for hotel PC installation and notification verification steps.
